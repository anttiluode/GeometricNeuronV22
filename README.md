# GeometricNeuronV22

A clean working repository for external tests of the Geometric Neuron idea.

The immediate goal is to compare simple morphology baselines against a small frozen graph/operator feature set on independently published neuron reconstructions and functional-complexity targets.

The first gate is currently **target-sealed** while the exact 24-cell morphology panel is recovered. See `docs/PROVENANCE_BLOCKERS.md` and issue #1; convenient morphology substitutions are not allowed after target values are opened.

A newer external boundary is recorded in `docs/TWINPROP_CONTACT.md`: detailed dendritic models have now been globally optimized for high-order nonlinear tasks, so any later V22 novelty must be narrower than “geometry can support complex computation.”

See `docs/` for the founding note, roadmap, paper contact, external gate, provenance ledger, and handoff.
