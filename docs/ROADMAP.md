# Roadmap

1. Parse the independently released morphology files.
2. Reproduce ordinary size and path statistics.
3. Build a sampling-density-resistant structural graph.
4. Compute the frozen three-feature operator panel.
5. Run the external leave-one-cell-out FCI gate exactly as written.
6. Preserve the result, including a null.
7. After the gate, run controlled simplifications to learn whether any effect comes from size, paths, topology, or the operator description.
8. Only after the external result is understood, consider a small artificial-model demo using whatever mechanism actually survived.

Each confirmatory stage should leave a frozen protocol, code, a machine-readable receipt, a short result note, and an explicit stop/continue decision.
