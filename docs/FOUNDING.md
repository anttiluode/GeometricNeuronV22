# Founding note

GeometricNeuronV22 is the clean convergence branch of a long experimental line.

The earlier question — "does geometry compute?" — was too permissive. Almost any distributed system can be described geometrically after the fact. V22 therefore asks a narrower question:

> What predictive or computational work is done by physical cable allocation, branching paths, and local nonlinear compartments beyond what simple morphology or ordinary algebraic baselines already explain?

## What survives from the earlier work

1. Frozen anatomy can be treated as an operator that constrains possible propagation and mixtures.
2. A graph/modal basis can be a useful microscope for that operator.
3. Local readout quality can depend strongly on where signals converge, not just on local energy.
4. Structural activity is not the same as structural credit; a growing branch should earn credit through measured change in behavior or information flow.
5. Strong simple baselines are mandatory. A geometric story that loses to a simpler size/path/algebraic model is not an earned geometric advantage.

## What does not carry forward as an assumption

V22 does not assume that biological neurons literally calculate graph eigenvectors. It does not assume that the generic HH-like event boundary explored in GeometricNeuronPlusField is computationally privileged. It does not assume that every temporal or spectral effect discovered in synthetic arbors maps to biology.

The graph representation is an instrument. The external prediction is the test.

## The current external collision

Aizenbud et al. (PNAS, 2026) report that modeled human cortical neurons have greater input/output functional complexity than modeled rat neurons, and that dendritic morphology contributes substantially to that difference. Their own simple morphology baselines are already strong. This is useful because it makes the first V22 experiment difficult rather than friendly.

The first question is therefore:

> Can a small frozen operator description of independently reconstructed dendritic trees predict held-out functional complexity beyond ordinary dendritic area and path descriptors?

If the answer is no, V22 records the null and narrows again.

## Repository rule

Old repositories are the laboratory notebook. V22 should contain only:

- concise statements of what survived;
- preregistered external tests;
- small reusable instruments;
- receipts, including nulls;
- new branches only when an external result or a failed assumption creates a genuinely new question.

Avoid adding degrees of freedom merely to rescue a failed gate.
